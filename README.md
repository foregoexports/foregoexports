# Forego Exports website

A simple, static one-page website ready for GitHub Pages.

## Publish it on GitHub Pages

1. Create a new GitHub repository, for example `foregoexports`.
2. Upload `index.html`, `style.css`, `script.js`, and `forego-logo.png` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will give you the live link in a few minutes. Connect `foregoexports.com` through your domain provider's DNS settings when ready.

## Before publishing

- The site uses `warehouse@foregoexports.com` for enquiries.
- Replace the image URLs in `style.css` with your own licensed images when you have product and farm photography.
